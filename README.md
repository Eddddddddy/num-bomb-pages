# 数字炸弹解码器

一个面向手机操作的 4 位数字炸弹解码器，适合通过 GitHub Pages 免费分发。

## 游戏规则

数字炸弹的答案由 4 个数字组成，范围是 `0000` 到 `9999`。

- 允许首位为 `0`，所以 `0123`、`0837`、`0008` 都是合法答案。
- 允许重复数字，所以 `0000`、`1111`、`6628`、`0909` 都是合法答案。
- 每一轮玩家猜一个 4 位数字。
- 出题方只反馈位置正确的个数，也就是有几个数字和答案在同一个位置上完全相同。
- 反馈值只能是 `0` 到 `4`。
- 不反馈“数字存在但位置不对”的数量。
- 反馈 `4` 表示猜中答案，游戏结束。

示例：如果真实答案是 `6248`：

| 猜测 | 反馈 | 解释 |
| --- | --- | --- |
| `6248` | `4` | 四个位置全部正确 |
| `6200` | `2` | 第 1 位 `6` 和第 2 位 `2` 正确 |
| `1234` | `0` | 没有任何数字在正确位置 |
| `6648` | `3` | 第 1、3、4 位正确，第 2 位错误 |

这个解码器每轮给出一个推荐猜测。你把这个数字告诉出题方，然后在页面里点击对方反馈的 `0`、`1`、`2`、`3` 或 `4`。程序会根据历史反馈过滤候选答案，并重新计算下一轮推荐。

## 功能

- 答案范围 `0000` 到 `9999`。
- 允许重复数字。
- 反馈只输入位置正确数量 `0` 到 `4`。
- 支持人类先验强度、重复数字权重、顺子惩罚、大小交叉奖励、直接猜中阈值等参数。
- 支持普通人默认局、防反套路局、强赌人性局三套预设。
- 可作为 PWA 添加到 iPhone 主屏幕，支持离线缓存。

## 参数和模式

页面中的 `?` 按钮会解释每个参数。核心思路如下：

- **预设方案**：一次性调整人性模型和求解策略。普通局适合大多数玩家；防反套路局适合对方知道你在用工具；强赌人性局更激进。
- **人类先验强度**：控制有多相信人类习惯。`0%` 等于所有答案等概率，`100%` 完全使用人性先验。
- **重复数字权重**：控制对子、两个对子、三个相同、四个相同这类答案的可信度。
- **顺子/单调惩罚**：降低 `1234`、`9876`、`1357`、`2468` 这类规律数字的先验概率。
- **大小交叉奖励**：提高 `2619`、`7283`、`0837` 这类有上下起伏节奏的数字概率。
- **直接猜中阈值**：当某个候选概率超过阈值时，程序直接建议猜它，而不是继续探测。
- **策略模式**：熵最大偏信息量，押高概率偏快速命中，防最坏偏稳。
- **允许非候选探针**：允许猜一个已经不可能是答案的数字来换取更多信息。
- **反馈错误容忍**：允许历史反馈里最多错一次，适合真人可能数错的情况。

## 本地运行

```bash
npm test
python3 -m http.server 4173
```

然后打开 `http://localhost:4173/`。

## GitHub Pages

这个项目不需要构建步骤。GitHub Pages 可以直接从 `main` 分支的仓库根目录发布。
